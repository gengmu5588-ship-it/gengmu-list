📐 等级算法

level = min(100, floor( sqrt( points / 200 ) ) + 1 )　　其中 points = 累计获得积分(totalGain) 上限曲线：V(L) 积分上限 = 200 × L²　→　V1<200，V2<800，V3<1800 … V13<33800 … V100≥1,960,200

例：累计 5000 分 → floor(√25)+1 = 6 → V6（黄金）；累计 33800 分 → V14；累计 ≥ 1,960,200 分封顶 V100（传奇）。
